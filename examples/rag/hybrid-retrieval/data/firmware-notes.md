# AtlasCam — Firmware 2.7 release notes

Maintenance release, recommended for all units.

- Scheduled reboot window can now be set per day of week.
- Idle power draw reduced by 8 % thanks to a deeper sensor sleep state.
- Two-way audio latency lowered on congested networks.
- Time-lapse clips can be exported directly to the mobile gallery.
- Resolved a certificate clock check regression introduced in 2.6: units
  showing E-417 on the screen recover automatically after this update.
  A reboot clears E-417 once the update is installed — no factory reset.
- Improved SD card wear levelling for continuous recording setups.
