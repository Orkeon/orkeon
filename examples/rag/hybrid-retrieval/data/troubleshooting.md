# AtlasCam — Troubleshooting common problems

When an error message appears on the display, note the code before
restarting. Most problems — an offline camera, a failed update, an app that
stops responding — are cured by a 10-second reset with the pin under the
base. If the same message comes back after restarting, check the network
connection and make sure the firmware is up to date. Persistent failures
usually indicate a hardware fault; contact support with the exact code
displayed.
