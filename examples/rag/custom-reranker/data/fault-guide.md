# SunCore inverter — Fault guide

If the inverter stops producing power, look at the status LED first. A red
LED means a fault was detected: the display cycles through the active fault
messages. The unit writes every fault to the maintenance log together with a code;
look the code up to understand what it means. Restart the unit with the DC
switch, wait two minutes, and check whether the fault clears. Faults that
persist after a restart usually point to wiring, an overheated enclosure,
or a grid outage.
