# Orkeon.Runners.ClaimVerification (`orkeon-claim-verify`)

Part of [Orkeon](https://github.com/Orkeon/orkeon) — build and orchestrate AI agent teams in .NET, described in declarative YAML, programmatic TypeScript (`.ork.ts`) or pure C#.

**orkeon-claim-verify** is an interactive claim-verification runner: a terminal REPL with TypeScript-scripted commands where crews of agents verify claims from a built-in catalog (or yours). It is one of the showcase runners bundled with the framework's examples.

## Install

```
dotnet tool install --global Orkeon.Runners.ClaimVerification --prerelease
orkeon-claim-verify
```

> This package is published on the [GitHub Packages feed](https://github.com/orgs/Orkeon/packages); add the feed as a NuGet source first — see the [publication matrix](https://github.com/Orkeon/orkeon/blob/main/docs/reference/publication-matrix.md).
