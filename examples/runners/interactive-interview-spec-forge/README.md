# Orkeon.Runners.InterviewSpecForge (`orkeon-spec-forge`)

Part of [Orkeon](https://github.com/Orkeon/orkeon) — build and orchestrate AI agent teams in .NET, described in declarative YAML, programmatic TypeScript (`.ork.ts`) or pure C#.

**orkeon-spec-forge** is an interactive interview-to-specification runner: a terminal REPL with TypeScript-scripted commands (`forge`, `topics`, `glossary`, `tasks`, `search`, `replay`…) where agent crews turn an interview over a document corpus into a structured specification. It is one of the showcase runners bundled with the framework's examples.

## Install

```
dotnet tool install --global Orkeon.Runners.InterviewSpecForge --prerelease
orkeon-spec-forge
```

> This package is published on the [GitHub Packages feed](https://github.com/orgs/Orkeon/packages); add the feed as a NuGet source first — see the [publication matrix](https://github.com/Orkeon/orkeon/blob/main/docs/reference/publication-matrix.md).
