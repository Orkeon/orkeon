## Points of attention (matrix §6.10)

- Run **without `--base-url`**: that is how, and only how, one verifies live that G-14 is closed — a bare `mistral-*` model must no longer head for `localhost:11434`.
- The host shown in the report header is the proof: `api.mistral.ai`, not `localhost`.
- `mistral-medium-2604` restricts `reasoning_effort` to `['high', 'none']` (measured 2026-08-30) — M7's default `low` is refused, hence the `m7Effort: high` in requiredParams.
- M10: the usage carries `prompt_tokens_details.cached_tokens` but the value stays 0 on an identical 5812-token prefix called twice (3 measurements, 2026-08-30). The field exists, the implicit cache does not engage — vendor red, not an Orkeon defect. Confirmed on the long prefix: still 0 at ~8200 tokens (2026-08-30).
- Identifiers mix aliases and dated snapshots: confirm the id on the official model card before freezing it. The compiled default was exactly that trap: `mistral-medium-3-5-26-04` (a concatenation of the `-3-5` alias and the `26-04` vintage) was never served — `Invalid model`, measured 2026-08-30, corrected to `mistral-medium-2604`.
