- Run **without `--base-url`**: that is how, and only how, one verifies live that G-14 is closed — a bare `mistral-*` model must no longer head for `localhost:11434`.
- The host shown in the report header is the proof: `api.mistral.ai`, not `localhost`.
- `mistral-medium-2604` restricts `reasoning_effort` to `['high', 'none']` (measured 2026-08-30) — M7's default `low` is refused, hence the `m7Effort: high` in requiredParams.
- M10: the usage carries `prompt_tokens_details.cached_tokens` but the value stays 0 on an identical 5812-token prefix called twice (3 measurements, 2026-08-30). The field exists, the implicit cache does not engage — vendor red, not an Orkeon defect. Confirmed on the long prefix: still 0 at ~8200 tokens (2026-08-30).
- Identifiers mix aliases and dated snapshots: confirm the id on the official model card before freezing it. The compiled default was exactly that trap: `mistral-medium-3-5-26-04` (a concatenation of the `-3-5` alias and the `26-04` vintage) was never served — `Invalid model`, measured 2026-08-30, corrected to `mistral-medium-2604`.
- 2026-10-07: the account is no longer rate-limited — the default is 11/1, its 2026-08-30 line, M10 still `0 cached` (the 2/10 of 2026-09-07 and 2026-09-21 measured the account). The catalogue (55 ids) publishes each model's context, capabilities, aliases and `default_model_temperature`: 1 for `mistral-medium-2604` and `mistral-large-4`, 0.3 for `mistral-small-2603`, `mistral-large-2512`, the ministral family and `codestral-2508`; `mistral-medium-2604` is now listed as an alias of `mistral-medium-latest`, with `mistral-medium-3-5` and `magistral-medium-latest`. `mistral-large-4` and `mistral-small-2603` restrict `reasoning_effort` to `high` / `none` like the default (`m7Effort`, requiredParams).
- `mistral-large-4` reasons by default and streams `delta.content` as an ARRAY of typed chunks (123 array deltas for 4 strings on a count to five, 2026-10-07): the text stream threw `InvalidOperationException: The requested operation requires an element of type 'String', but the target element has type 'Array'` (M3 red, archived 18:14) and the chat stream dropped the trace and the first words of the answer.
