## Points of attention (matrix decision)

- A **decision provider**, not a chat one: none of M1–M13 applies. The probe runs the D modes (`orkeon llm probe -p typesafe`) through the same `SystemOneDecisionModel` the framework uses; `liquid` and `kev` take the same modes.
- No temperature: the report header says `not pinned`, which is the truth — the System One wire has no sampling parameter.
- D4 (Box) sends a 320×320 PNG: TypeSafe rejects an image with a side under 280 pixels (`Invalid image dimensions`). Box is *dreamer-ready* by TypeSafe's own word: on 2026-11-11 Jev 1.14 drew the box 0.1–0.15 too low, varying from call to call, so D4 passes on a box that touches the digits and reports the IoU rather than judging it.
- 2026-11-11, first campaign: jev-latest and jev-preview both serve `jev-1.14.0`, 7/7 each (D4 IoU about 0.4). The two integration tests sent a bare noul and were refused (`Noul question must have criteria or instructions`) — the tests were wrong, not the adapter; fixed in 925c13871.
