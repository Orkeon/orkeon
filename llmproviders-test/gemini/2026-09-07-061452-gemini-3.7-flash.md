## Points of attention (matrix §6.13)

- Arrived **after** the 2026-07-27 audit: it carries no inherited G-xx gap, and its §6.13 sheet was opened without a campaign. This one is its first real execution proof.
- **OpenAI-compatibility** endpoint (`generativelanguage.googleapis.com/v1beta/openai`) — neither the native Gemini API nor Vertex AI. The host carried by the report header is what confirms it.
- **M8 is no longer ➖**: measured on 2026-08-30, the compatibility surface accepts `response_format` `json_object` **and** `json_schema`, schema validated server-side (`additionalProperties` included). The provider declares `JsonSchema` since that date — the warning it used to emit refused something that works.
- M3/M4 stream in large blocks (~13 characters per event): a reply that is too short fits in a single chunk and reads like a buffered fallback. The probe asks for a hundred numbers since 2026-08-30 to discriminate (thirty were enough here, but claude-sonnet-5 coalesced thirty into a single delta).
- M7 is **effort only** (`reasoning_effort` translated to `thinking_level`): neither toggle nor token budget, unlike Qwen.
- The default model sees: M9 is exercised on it, with no companion vision campaign.
