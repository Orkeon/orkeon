## Points de vigilance (matrice §6.2)

- Dialecte propre (Messages API) : c'est le provider qui porte le plus de code spécifique.
- M8 est **schéma obligatoire** — `output_config.format` n'a pas d'équivalent de `json_object`.
- M10 n'a de sens qu'avec un breakpoint explicite : sans `cache_control`, Anthropic ne cache rien (G-17). Le harnais l'active de lui-même ici.
- M4 doit confirmer le SSE natif livré par LLM-05 (G-20), et non un repli bufferisé.
- Les clés identity-linked exigent l'en-tête `anthropic-workspace-id` sur chaque requête (mesuré 2026-08-30). Déclarer `workspaceId` dans le JSON de campagne ou passer `--workspace-id` ; les clés classiques n'en ont pas besoin.
- `claude-sonnet-5` refuse toute température explicite autre que 1 (`temperature is deprecated for this model`, mesuré 2026-08-30 : 1 et l'omission passent, 0 et 0.7 non) — même classe que `kimi-k2.6` et `gpt-5.6-sol`, même remède : le catalogue l'épingle pour ce modèle (requiredParams), l'en-tête du rapport porte la valeur utilisée.
