## Points of attention (matrix §6.2)

- Own dialect (Messages API): this is the provider carrying the most specific code.
- M8 is **schema mandatory** — `output_config.format` has no `json_object` equivalent.
- M10 only makes sense with an explicit breakpoint: without `cache_control`, Anthropic caches nothing (G-17). The harness enables it on its own here.
- M4 must confirm the native SSE delivered by LLM-05 (G-20), not a buffered fallback.
- Identity-linked keys require the `anthropic-workspace-id` header on every request (measured 2026-08-30). Declare `workspaceId` in the campaign JSON or pass `--workspace-id`; classic keys need nothing.
- `claude-sonnet-5` refuses any explicit temperature other than 1 (`temperature is deprecated for this model`, measured 2026-08-30: 1 and omission pass, 0 and 0.7 do not) — same class as `kimi-k2.6` and `gpt-5.6-sol`, same remedy: the catalog pins it for this model (requiredParams), the report header carries the value used.
- Catalogue read of 2026-10-07 (14 ids; the endpoint publishes context, output cap, effort levels and thinking types per model — see served-models.json). Four more models refuse a pinned temperature in the same words (`temperature is deprecated for this model.`): `claude-opus-5`, `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5` — pinned to 1 (requiredParams); 12/12, 10/2, 12/12, 11/1. The listing itself needs the workspace header on an identity-linked key, and `orkeon llm models` cannot send it: the list was read with a direct call. `GET /v1/organizations/workspaces` answers that same key with the workspace ids.
- A refusal is NOT an empty answer, and the provider reads it as one (measured 2026-10-07): on `claude-opus-5-5` the probe's M5/M6 prompt (`the sealed probe code … cannot be guessed`) comes back HTTP 200 with `content: []`, `stop_reason: "refusal"` and `stop_details: {category: "cyber", explanation: …}` — 3 of 4 M5 and 4 of 4 M6. `AnthropicLlmProvider` does not read `stop_reason`, so the report shows `no tool call in the reply:` followed by nothing. On that model those reds measure the classifier meeting the probe's wording, not tool calling — `claude-sonnet-5`, `claude-sonnet-5-5`, `claude-opus-5` and `claude-haiku-5-5` answer the same prompt. `claude-fable-5-1` shows the same empty M6 since 2026-09-21 (three more today), but one direct call with the same wording was answered (`end_turn`, a text block): its cause is not established.
