# Orkeon.Tools.EventHub

Part of [Orkeon](https://github.com/Orkeon/orkeon) — build and orchestrate AI agent teams in .NET, described in declarative YAML, programmatic TypeScript (`.ork.ts`) or pure C#.

**Orkeon.Tools.EventHub** gives agents access to Orkeon's inter-agent and inter-crew messaging: `publish_event`, `post_message`, `send_request`, `reply_to`, `receive_message`, `wait_for_event`, `get_last_value`.

## Install

```
dotnet add package Orkeon.Tools.EventHub
```
