# Orkeon.Tools.Embeddings.Local

Part of [Orkeon](https://github.com/Orkeon/orkeon) — build and orchestrate AI agent teams in .NET, described in declarative YAML, programmatic TypeScript (`.ork.ts`) or pure C#.

**Orkeon.Tools.Embeddings.Local** provides local, on-device embeddings for Orkeon (BGE-micro-v2 via ONNX, 384 dimensions, CPU-only) — semantic memory search and agent selection with no API key and no network calls.

## Install

```
dotnet add package Orkeon.Tools.Embeddings.Local --prerelease
```

> Published to NuGet.org as part of the consolidated lineup (from `v1.0.0-rc.3`; earlier versions reached the GitHub Packages feed only); depends on the [`Orkeon`](https://www.nuget.org/packages/Orkeon) package — see the [publication matrix](https://github.com/Orkeon/orkeon/blob/main/docs/reference/publication-matrix.md).
