# Orkeon.Tools.Data

Part of [Orkeon](https://github.com/Orkeon/orkeon) — build and orchestrate AI agent teams in .NET, described in declarative YAML, programmatic TypeScript (`.ork.ts`) or pure C#.

**Orkeon.Tools.Data** ships the data-manipulation agent tools: JSON, CSV, XML and PDF processing, database queries, email parsing and more.

## Install

```
dotnet add package Orkeon.Tools.Data
```
