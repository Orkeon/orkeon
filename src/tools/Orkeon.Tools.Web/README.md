# Orkeon.Tools.Web

Part of [Orkeon](https://github.com/Orkeon/orkeon) — build and orchestrate AI agent teams in .NET, described in declarative YAML, programmatic TypeScript (`.ork.ts`) or pure C#.

**Orkeon.Tools.Web** ships the web-facing agent tools: web scraping, HTTP API calls, search, GitHub, image generation, and `firefox` — the Firefox of the machine driven over WebDriver BiDi, with the page read as a semantic graph ([guide](https://github.com/Orkeon/orkeon/blob/main/docs/guides/firefox.md)).

## Install

```
dotnet add package Orkeon.Tools --prerelease
```

> This assembly ships inside the [`Orkeon.Tools`](https://www.nuget.org/packages/Orkeon.Tools) package — the eight built-in tool families in one install; it is no longer a standalone NuGet package. See the [publication matrix](https://github.com/Orkeon/orkeon/blob/main/docs/reference/publication-matrix.md).
