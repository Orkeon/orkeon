# Orkeon.Tools.Analysis

Part of [Orkeon](https://github.com/Orkeon/orkeon) — build and orchestrate AI agent teams in .NET, described in declarative YAML, programmatic TypeScript (`.ork.ts`) or pure C#.

**Orkeon.Tools.Analysis** exposes RaggableTree to agents as 15 tools — `index_codebase`, `codebase_map`, `symbol_detail`, `flow_trace`, `impact_analysis`, `complexity_report`, `codebase_search` and friends — so crews can navigate and reason over a semantic graph of a codebase.

## Install

```
dotnet add package Orkeon.Tools.Analysis
```
