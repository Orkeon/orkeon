# Orkeon.Cli

Part of [Orkeon](https://github.com/Orkeon/orkeon) — build and orchestrate AI agent teams in .NET, described in declarative YAML, programmatic TypeScript (`.ork.ts`) or pure C#.

**Orkeon.Cli** ships the reusable common commands for interactive Orkeon runners (`help`, `exit`, `clear`) and the `DefaultCommandRegistry` that discovers and dispatches them.

## Install

```
dotnet add package Orkeon.Cli
```
